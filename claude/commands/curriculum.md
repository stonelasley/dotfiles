# Curriculum

Invoke the skill with the provided arguments:

```
Skill("Curriculum", "$ARGUMENTS")
```

The Curriculum skill interviews you with progressively harder questions to find the
edge of your understanding, checks whether the subject fits the hours you have,
rescopes it into a track of six-week sections when it doesn't, and writes a plan with
one testable capability per week and a capstone. Existing courses route to a study
session or a weekly review instead of a fresh interview.
